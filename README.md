# Psycholinguistics & NLP Academic Website

A responsive academic homepage starter using plain HTML and CSS. Inspired by clean academic personal websites, with sections for About, Research Interests, Publications, Projects, Education, Teaching, Notes, and CV.

## Files

- `index.html` — all site content
- `style.css` — design and responsive layout
- `assets/profile-placeholder.svg` — temporary portrait placeholder
- `assets/cv.pdf` — add your CV PDF here when ready

## Customize the content

1. Open `index.html`.
2. Replace `Your Name`, `[position]`, `[department / institution]`, and all other bracketed placeholders.
3. Update email, Google Scholar, GitHub, and LinkedIn URLs.
4. Replace the sample publications and project descriptions with accurate details. Delete entries that don't apply.
5. Add your photo to `assets/`, for example `profile.jpg`. Change the image line in `index.html` to:
   `<img src="assets/profile.jpg" alt="Portrait of Your Name">`
6. Add your CV PDF as `assets/cv.pdf`, or remove the download button until it is ready.
7. If you don't teach or write public notes, remove those sections and their navigation links.

## Preview locally

Double-click `index.html` to open it in your browser. No server or build tools are required.

## Publish with GitHub Pages

1. Create a public GitHub repository named exactly `YOUR-USERNAME.github.io`.
2. Upload the contents of this folder to the repository root (not just the ZIP file).
3. In the repository, go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select branch `main` and folder `/(root)`, then save.
5. Wait for deployment and visit `https://YOUR-USERNAME.github.io/`.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Design adjustments

At the top of `style.css`, change CSS variables such as `--accent`, `--page`, `--text`, and `--max-width` to tune the colors and width.

## Privacy

A published GitHub Pages site is public. Review your CV, photos, research materials, and contact details before publishing. Don't upload confidential or unpublished materials you are not ready to share.
